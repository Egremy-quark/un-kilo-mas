# Bloques de Un Kilo Más

Cada archivo JSON de esta carpeta es un bloque general, el mismo para todas las personas.

Para cargar uno nuevo, sin tocar código:

1. Copia `plantilla.json.ejemplo` o un JSON de prueba y guarda un `.json` nuevo.
2. Pon `es_prueba: false` solo cuando el contenido lo haya entregado Yohan.
3. El contenido real (ejercicios, series, repeticiones, progresiones, notas) es `[CONTENIDO POR YOHAN]`.
4. Corre `npm run bloques`.

La app lee de la base, no de estos archivos. Este directorio es la fuente para cargarlos.

Las Rutinas 01 y 02, cuando Yohan las entregue, entran aquí como dos bloques más. No hace falta otra tabla.
